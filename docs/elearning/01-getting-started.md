# 1. البداية

## تسجيل الدخول

1. افتح صفحة التطبيق.
2. أدخل «البريد الإلكتروني» و«كلمة المرور».
3. اضغط «تسجيل الدخول».

📷 صورة: شاشة تسجيل الدخول.

رسائل قد تظهر لك:

| الرسالة | المعنى وما تفعله |
| --- | --- |
| «البريد الإلكتروني أو كلمة المرور غير صحيحة.» | تأكد من البيانات وأعد المحاولة. |
| «يجب أن تتكون كلمة المرور من 8 أحرف على الأقل.» | كلمة المرور قصيرة. |
| «محاولات تسجيل الدخول كثيرة جدًا…» | انتظر دقيقة واحدة ثم حاول مجددًا. |
| «المستأجر غير نشط…» | حساب المتجر متوقف، تواصل مع مسؤول المنصة. |

- **أول دخول:** يحصل المستخدم الجديد على «كلمة مرور مؤقتة» من الشخص الذي دعاه (المالك أو المسؤول). غيّرها بعد أول دخول.
- **نسيت كلمة المرور؟** تواصل مع مالك المتجر أو مسؤول المنصة لإعادة تعيينها.
- تسجيل الدخول يحتاج دائمًا إلى اتصال بالإنترنت.

## الصفحة الرئيسية «الرئيسية»

بعد الدخول تظهر صفحة «مرحبًا بك في مساحة عمل متجرك». فيها:

- قسم «روابط سريعة»: بطاقة لكل صفحة مسموح لك بفتحها (المنتجات، لوحة التحكم، الزبائن، الموردون، الموظفون، فواتير، التقارير، الفئات). اضغط على البطاقة للانتقال.
- ثلاث بطاقات تعريفية: «إدارة متجرك»، «متابعة العمل اليومي»، «ابقَ مسيطرًا».

إذا لم تكن الصفحة الرئيسية مسموحة لك، ينقلك التطبيق مباشرة إلى المنتجات أو الفواتير.

📷 صورة: الصفحة الرئيسية مع الروابط السريعة.

## الشريط العلوي (يظهر في كل الشاشات)

| العنصر | الوظيفة |
| --- | --- |
| الشعار «ريڤو» | العودة إلى الصفحة الرئيسية |
| روابط الصفحات | «الرئيسية»، «لوحة التحكم»، «المنتجات»، «المشاريع»، «الزبائن»، «الموردون»، «فواتير»، «التقارير»، «الفئات»، «الشركاء»، «الموظفون»، «المستخدمون» — تظهر فقط الصفحات المسموحة لك |
| «المستودعات» | اختيار المستودع الذي تعمل عليه (انظر القسم 2) |
| أيقونة غرفة الأخبار | آخر التحديثات والميزات الجديدة في التطبيق، مع عدد غير المقروء |
| الجرس «الإشعارات» | تنبيهات يومية عن المنتجات وتنبيهات الاشتراك |
| «إضافة سريعة» | إضافة سريعة لزبون، مورد، نوع نفقات، وحدة، فئة، علامة تجارية، شريك، رف، مستودع |
| الترس | الإعدادات |

📷 صورة: الشريط العلوي مع شرح كل أيقونة.

### الإشعارات

يعرض الجرس قوائم يومية مثل:

- «منتجات بكمية سالبة»
- «منتجات بسعر شراء مفقود أو صفر»
- «منتجات بسعر بيع مفقود أو صفر»
- «منتجات بسعر بيع أقل من سعر الشراء»
- «منتجات بمخزون يساوي الحد الأدنى أو أقل»

ننصح بمراجعتها كل يوم، لأن المنتجات بدون سعر شراء تجعل حساب الربح غير دقيق (انظر القسم 16).

### الإضافة السريعة

اضغط «إضافة سريعة» ← «اختر ما تريد إضافته» ← اختر البطاقة ← املأ الاسم ← احفظ.

- الزبون والمورد والفئة والشريك: تحتاج صلاحية الإضافة الخاصة بها.
- النفقات والوحدة والعلامة التجارية والرف والمستودع: يحفظها المالك أو المسؤول فقط.
- **المستودعات والرفوف والوحدات تُضاف من هنا فقط.**

### الجوال

على الشاشات الصغيرة تجد الروابط داخل زر القائمة (☰)، ومعها «تغيير كلمة المرور» و«تسجيل الخروج».

## تغيير كلمة المرور

من القائمة ← «تغيير كلمة المرور» ← أدخل الحالية ثم الجديدة مرتين.

- يجب ملء كل الحقول.
- يجب أن تتطابق كلمتا المرور الجديدتان.
- يجب أن تختلف الجديدة عن الحالية.

## انتهاء الاشتراك

عند انتهاء اشتراك المتجر يصبح التطبيق **للعرض فقط**: «يمكنك عرض بياناتك فقط. الإضافة والتعديل والحذف معطّلة حتى يتم تجديد الاشتراك.»
يستطيع المالك أو المسؤول إرسال «طلب تجديد الاشتراك».
