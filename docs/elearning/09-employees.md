# 9. الموظفون

**الوصول:** الشريط العلوي ← «الموظفون». يحتاج اتصالًا بالإنترنت.

## قائمة الموظفين

- تبويبات «الحاليون» / «المنتهون».
- البحث بالاسم أو الهاتف أو المعرّف.
- الأعمدة: «الاسم»، «نوع التوظيف»، «الحالة»، «تاريخ البدء»، «الراتب الحالي».

## إضافة موظف

«إضافة موظف» ← «الاسم» و«نوع التوظيف» («دوام كامل» / «دوام جزئي» / «بالساعة» / «أخرى») و«تاريخ البدء» إلزامية؛ الهاتف والعنوان اختياريان.

## ملف الموظف

📷 صورة: ملف موظف، تبويب الراتب.

- **«نظرة عامة»:** الحالة «نشط» / «غير نشط» / «في إجازة» / «منتهٍ». عند اختيار «منتهٍ» يجب إدخال «تاريخ الانتهاء».
- **«جدول العمل»:** أيام العمل ووقت البدء والانتهاء.
- **«الراتب»:**
  - «سجل الراتب» ← «إضافة راتب»: «نوع الدفع» (شهري / بالساعة)، «المبلغ»، «العملة»، «تاريخ السريان»، «أجر الإضافي».
    «الراتب الحالي» هو آخر راتب تاريخ سريانه اليوم أو قبله، لذلك يمكنك تسجيل زيادة مستقبلية مسبقًا.
  - «المدفوعات» ← «إضافة دفعة»: التاريخ والمبلغ والعملة والملاحظة. يمكن تعديلها وحذفها.
- **«الحضور» و«الإجازات»:** قيد التطوير.

> **مهم:** دفعات الموظف في هذه الصفحة للتوثيق فقط و**لا تُخرج مالًا من الصناديق**. لتسجيل خروج المال من الصندوق أضف أيضًا «سند نفقات». لا يحسب التطبيق حاليًا الرصيد المتبقي للموظف (الراتب ناقص الدفعات)، ولا توجد ميزة سُلف.
