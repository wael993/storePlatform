# 15. النسخ الاحتياطي والاستعادة

**الوصول:** الإعدادات ← «النسخ الاحتياطي». **للمالك فقط**، وإذا كانت الميزة مفعّلة لمتجرك. يحتاج اتصالًا بالإنترنت.

يحفظ التطبيق نسخًا **مشفّرة** من كل بيانات متجرك في حساب التخزين السحابي الخاص بك.

📷 صورة: تبويب النسخ الاحتياطي.

## ربط التخزين

1. اختر Google Drive أو Dropbox أو OneDrive.
2. «ربط» ← سجّل الدخول إلى حسابك ووافق.
3. «استخدامه للنسخ الاحتياطي».

يمكن لاحقًا «تغيير الحساب» أو «فصل».

## النسخ التلقائي واليدوي

- **«نسخ احتياطي تلقائي ليلي»:** نسخة كل ليلة، **فقط إذا تغيّرت البيانات**. يحتاج ربط التخزين أولًا.
- **«نسخ احتياطي الآن»:** نسخة فورية.
- يحتفظ التطبيق بآخر 3 نسخ ناجحة (يمكن لمسؤول المنصة زيادتها حتى 30).

## سجل النسخ

«التاريخ»، «النوع» («تلقائية» / «يدوية» / «أمان (قبل الاستعادة)»)، «التخزين»، «الحجم»، «الحالة».

## الاستعادة

> **تحذير:** الاستعادة **تستبدل كل بيانات المتجر** بالنسخة المختارة. كل ما أُضيف بعد تاريخ النسخة يُفقد.

1. اختر النسخة ← «استعادة» ← أكّد.
2. ينشئ التطبيق أولًا نسخة أمان من الوضع الحالي، فيمكنك التراجع.
3. أثناء الاستعادة لا يمكن لأحد التعديل.
4. بعد الانتهاء: «أعد تحميل التطبيق».
5. الأجهزة التي لديها تغييرات غير متزامنة (بدون اتصال) تُسأل هل تزامنها أو تتجاهلها.
