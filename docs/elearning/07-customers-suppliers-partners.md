# 7. الزبائن والموردون والشركاء

**الوصول:** الشريط العلوي ← «الزبائن» / «الموردون» / «الشركاء».

الصفحات الثلاث متشابهة.

| الصفحة | الأعمدة |
| --- | --- |
| الزبائن | «اسم الزبون»، «رمز الزبون»، «إجمالي المستحق» (حسب الصلاحية) |
| الموردون | «اسم المورد»، «رمز المورد»، «إجمالي المستحق للدفع» (حسب الصلاحية) |
| الشركاء | «اسم الشريك»، «رمز الشريك»، «تاريخ الإنشاء» |

📷 صورة: صفحة الزبائن.

## إضافة

«إضافة زبون» / «إضافة مورد» / «إضافة شريك» ← الاسم والرمز (يقترح التطبيق رمزًا تلقائيًا) ← حفظ.
أو من «إضافة سريعة».

## حذف

حذف سجل واحد أو عدة سجلات محددة. **ممنوع** إذا كان مستخدمًا في فواتير أو مشاريع أو سندات. يحتاج اتصالًا.

## صفحة الطرف (كشف الحساب)

اضغط على الاسم لفتح صفحة الطرف.

📷 صورة: صفحة زبون مع البطاقات والقائمة.

### البطاقات

- «إجمالي فواتير البيع» (أو «إجمالي فواتير الشراء» للمورد).
- الرصيد: **«مستحق لنا»** (الطرف مدين لنا) أو **«مستحق علينا»** (نحن مدينون له).

### القائمة

كل فواتير وسندات هذا الطرف، مع «الإجمالي» و«المدفوع» و«المتبقي» و«الرصيد» المتراكم، وإجراءات العرض والتعديل والطباعة والحذف.

### الأزرار

«فاتورة جديدة» (مع الجملة ونصف الجملة)، «فاتورة شراء»، «سندات». المستند الجديد يُربط بهذا الطرف تلقائيًا.

### المبالغ بالعملات الأخرى

مرّر الفأرة على أي مبلغ لرؤيته بالعملات الأخرى («عملات أخرى»).

## الرصيد الافتتاحي

للزبائن والموردين فقط (ليس للشركاء والمشاريع). يُستخدم عند بدء العمل بالتطبيق لتسجيل الديون القديمة.

1. صفحة الطرف ← «الرصيد الافتتاحي».
2. سطر لكل عملة («إضافة عملة» لإضافة عملة أخرى).
3. لكل سطر اختر «مستحق لنا» أو «مستحق علينا» وأدخل المبلغ.
4. احفظ.

> الرصيد الافتتاحي بعملة ثانوية يُحوَّل إلى العملة الأساسية **بسعر الصرف الحالي** في كل مرة، لذلك قد يتغير الرصيد المعروض إذا تغيّر سعر الصرف. طريقة حساب الرصيد في القسم 16.

## طرف هو زبون ومورد في نفس الوقت

إذا كنت تبيع لنفس الشخص وتشتري منه، يحسب التطبيق الرصيد الصافي: ما عليه من فواتير البيع ناقص ما له من فواتير الشراء.
