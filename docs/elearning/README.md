## مصطلحات أساسية

- **المستودع:** مكان تخزين البضاعة. لكل منتج كمية مستقلة في كل مستودع.
- **العملة الأساسية:** العملة التي تُحسب بها كل التكاليف والأرباح والأرصدة.
- **الصندوق (حساب النقد):** لكل مستودع ثلاثة صناديق: «اليومي» و«الخزنة» و«أونلاين».
- **السند:** حركة مالية بدون منتجات (قبض، دفع، نفقات، تحويل، صرافة).
- **متوسط التكلفة:** تكلفة الوحدة الواحدة من المنتج في مستودع معيّن، وتتغير مع كل فاتورة شراء.
