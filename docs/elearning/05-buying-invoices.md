# 5. فواتير الشراء

**الوصول:** الشريط العلوي ← «فواتير» ← زر «فاتورة شراء». أو من صفحة المورد ← «فاتورة شراء».

فاتورة الشراء تزيد المخزون وتحدّث **متوسط التكلفة**. لذلك هي أهم مستند لحساب الربح الصحيح.

## إنشاء فاتورة شراء

1. اختر مستودعًا واحدًا، ثم «فاتورة شراء».
2. **«المورد»** (إلزامي). إذا لم يكن موجودًا ولديك الصلاحية يمكنك إنشاؤه مباشرة.
3. «مندوب المبيعات» (إلزامي)، التاريخ، الوقت.
4. أضف المنتجات بالبحث أو الباركود. المنتج غير الموجود يمكن إنشاؤه (بصلاحية إضافة المنتجات).
5. لكل سطر: «الكمية» (1 على الأقل) و«افرادي» = **سعر شراء الوحدة**.
6. «نوع الدفع»: نقدًا أو بطاقة أو آجل، والصندوق الذي يخرج منه المال.
7. احفظ.

📷 صورة: فاتورة شراء معبأة.

### قواعد

- الدفع النقدي أو بالبطاقة يُرفض إذا لم يكفِ رصيد الصندوق: «المبلغ يتجاوز الرصيد المتاح».
- إذا أدخلت السعر بعملة ثانوية يحوّله التطبيق إلى العملة الأساسية بسعر الصرف المحفوظ.
- **الخصم على فاتورة الشراء لا يخفّض متوسط التكلفة.** التكلفة تُحسب من سعر الوحدة قبل الخصم. إذا أردت أن تنعكس الخصومات على التكلفة، أدخل سعر الوحدة بعد الخصم.

### ماذا يحدث عند الحفظ

- تزيد الكمية في المستودع المختار.
- يُعاد حساب متوسط التكلفة (المتوسط المرجّح، مثال في القسم 16).
- يخرج المبلغ المدفوع من الصندوق.
- يزيد المبلغ المتبقي على حساب المورد (مستحق علينا).

### تعديل وحذف

- **التعديل:** يعكس الأسطر القديمة ثم يسجل الجديدة كعملية شراء جديدة.
- **الحذف:** ينقص الكمية من المخزون (وقد تصبح سالبة إذا بيعت البضاعة) ويعيد المال إلى الصندوق.
- **تنبيه:** حذف أو تعديل فاتورة شراء **لا يعيد متوسط التكلفة القديم**. راجع التكلفة بعد تصحيح فاتورة شراء خاطئة.

## قراءة الفاتورة بالذكاء الاصطناعي

إذا كانت الميزة مفعّلة لمتجرك:

1. داخل فاتورة الشراء ← «رفع فاتورة» ← «قراءة بالذكاء الاصطناعي». يعرض الزر العدد المتبقي هذا الشهر («{{count}} متاح»).
2. ارفع صورة أو ملف فاتورة المورد.
3. يقرأ التطبيق المورد والمنتجات والكميات والأسعار ويحاول مطابقتها مع الموجود.
4. **الحقول المميزة** (غير المؤكدة) يجب تأكيدها أو تصحيحها: «أكد أو صحح الحقول المميزة قبل الاعتماد».
5. للمنتجات أو المورد غير الموجودين: «إنشاء منتج جديد» / «إنشاء مورد جديد».
6. «اعتماد الفاتورة» أو «رفض الاستيراد».

تحتاج هذه الميزة اتصالًا بالإنترنت.

📷 صورة: شاشة مراجعة القراءة بالذكاء الاصطناعي.
