# 10. لوحة التحكم وسجل النقد

**الوصول:** الشريط العلوي ← «لوحة التحكم» (عليها شارة «Beta»). تحتاج اتصالًا بالإنترنت، وتعرض بيانات المستودع أو المستودعات المختارة.

📷 صورة: لوحة التحكم كاملة.

## الفترة

«من» / «إلى» في الأعلى. الافتراضي: من أول الشهر حتى اليوم.

## «نظرة عامة»

| البطاقة | ماذا تعرض |
| --- | --- |
| «عدد المنتجات» | عدد المنتجات |
| «الزبائن المسجلون» / «زبائن جدد» | عدد الزبائن، والجدد خلال الفترة |
| «تكلفة المخزون» | قيمة البضاعة الموجودة بسعر التكلفة. تظهر بلون مميز إذا كانت هناك منتجات بدون تكلفة |
| «فواتير اليوم» | فواتير اليوم المرحّلة فقط (لا تتأثر بالفترة) |
| «مبيعات الفترة» | مجموع فواتير البيع في الفترة |
| «الربح» | ربح الفترة. يظهر بلون مميز إذا بيعت منتجات بدون تكلفة |
| «إجمالي المستحقات لنا» / «علينا» | ديون الزبائن والموردين (بدون الشركاء) |

طريقة حساب كل رقم في القسم 16.

## «رصيد الصندوق»

أرصدة «اليومي» و«الخزنة» و«أونلاين» و«الإجمالي» **لكل عملة على حدة** (لا تُحوَّل إلى العملة الأساسية). «عرض كل العملات» لعرض الكل. الضغط على صندوق يفتح «سجل النقد» لهذا الصندوق (حسب الصلاحية).

## «المخزون»

- «تحذيرات المخزون»: أعداد المنتجات ذات المشاكل (كمية سالبة، بدون سعر، تحت الحد الأدنى…)، والضغط يفتح القائمة.
- «أفضل المنتجات ربحاً» و«الأكثر مبيعاً»: أفضل 5 منتجات. يمكن التصفية حسب «المورد».

أقسام «المبيعات والأرباح» (الرسوم البيانية) و«النشاط» قادمة قريبًا.

## سجل النقد

**الوصول:** لوحة التحكم ← الضغط على بطاقة صندوق.

📷 صورة: سجل النقد مع المرشحات.

- **المرشحات:** «الحساب»، «النوع»، الفترة ← «تطبيق». الفترة تشمل أيامًا كاملة بتوقيت عمّان.
- **الأعمدة:** «التاريخ»، «الحساب»، «النوع»، «المبلغ»، «المرجع»، «السبب»، «بواسطة».
- **أنواع الحركات:** «بيع»، «شراء»، «قبض»، «دفع»، «مصروف»، «تحويل»، «صرافة»، «رصيد افتتاحي»، «تعديل»، «عكس».

السجل لا يُعدَّل أبدًا. عند حذف فاتورة أو سند تظهر حركة «عكس» جديدة بدل حذف الحركة الأصلية، لذلك يبقى كل شيء قابلًا للتتبع.
