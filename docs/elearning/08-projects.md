# 8. المشاريع

**الوصول:** الشريط العلوي ← «المشاريع».

المشروع يجمع كل ما يخص عملًا أو عقدًا معيّنًا (مثلًا تجهيز محل لزبون) لمعرفة ربحه.

## قائمة المشاريع

الأعمدة: «اسم المشروع»، «رمز المشروع» (يُقترح تلقائيًا)، «الإجمالي». «إضافة مشروع» لإنشاء مشروع جديد.

## صفحة المشروع

📷 صورة: صفحة مشروع مع البطاقات.

البطاقات:

| البطاقة | المعنى |
| --- | --- |
| «تكلفة العقد» | قيمة العقد المتفق عليها مع الزبون (تُضبط بزر خاص) |
| «سندات القبض» | المبالغ المستلمة لهذا المشروع |
| «تكاليف الموظفين» | مجموع سندات «تكلفة موظف» |
| «التكاليف الأخرى» | مجموع سندات «تكاليف أخرى» |
| «الربح» | نتيجة المشروع حسب هذه المبالغ |

الأزرار:

- «فاتورة جديدة»: فاتورة بيع على المشروع.
- «سندات»: قبض أو دفع على المشروع.
- «تكلفة موظف»: اختر الموظف والمبلغ.
- «تكاليف أخرى»: اكتب «اسم التكلفة» والمبلغ.

> «تكلفة موظف» و«تكاليف أخرى» تُسجل على المشروع فقط ولا تُخرج مالًا من الصناديق. إذا دفعت المال فعلًا سجّل أيضًا سند دفع أو نفقات.

يمكن أيضًا اختيار المشروع كـ«زبون» في فاتورة البيع وفي السندات.
