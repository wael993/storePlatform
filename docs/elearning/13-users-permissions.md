# 13. المستخدمون والأدوار والصلاحيات

**الوصول:** الشريط العلوي ← «المستخدمون».

## الأدوار

| الدور | الوصف |
| --- | --- |
| «المالك» | يرى كل الصفحات المفعّلة وكل المستودعات. هو الوحيد الذي يدير الصلاحيات، ويحدد مستودعات المستخدمين، ويمنح دور المالك، ويدير النسخ الاحتياطي. لا يمكن حذفه |
| «مسؤول» | حسب الصلاحيات التي يمنحها المالك. يستطيع أيضًا استيراد المنتجات وحفظ الإضافات السريعة (وحدة، مستودع…) وطلب تجديد الاشتراك |
| «أمين صندوق» | حسب الصلاحيات التي يمنحها المالك |
| «موظف» | حسب الصلاحيات التي يمنحها المالك |

الأدوار الثلاثة الأخيرة تبدأ بصلاحيات قليلة: الصفحة الرئيسية، المنتجات، صفحة الفواتير، قائمة فواتير البيع، وزر فاتورة بيع جديدة. كل ما عدا ذلك يمنحه المالك.

## دعوة مستخدم

تبويب «دعوة مستخدم»:

1. «الاسم الأول»، «اسم العائلة»، «البريد الإلكتروني» (بنفس نطاق بريد المتجر)، «الدور».
2. اضغط دعوة.
3. تظهر **«كلمة المرور المؤقتة»**. أعطها للمستخدم بنفسك، فالتطبيق لا يرسلها بالبريد.

📷 صورة: نموذج الدعوة وكلمة المرور المؤقتة.

## قائمة المستخدمين

تبويب «المستخدمون»: «الاسم»، «البريد الإلكتروني»، «الدور» (قابل للتغيير)، «صلاحية المستودع» (للمالك فقط)، «حذف» (لا يمكن حذف المالك أو نفسك).

### صلاحية المستودع

يحدد المالك المستودعات التي يعمل عليها كل مستخدم. المستخدم بدون مستودعات لا يرى أي مخزون أو فواتير.

## صلاحيات الدور

تبويب «صلاحيات الدور» (للمالك فقط):

1. اختر الدور.
2. لكل صفحة حدد «رؤية» / «إضافة» / «تعديل» / «حذف».
3. «حفظ».

📷 صورة: جدول صلاحيات الدور.

- الصلاحيات شجرة: إلغاء صلاحية رئيسية يلغي ما تحتها.
- أمثلة على صلاحيات دقيقة: رؤية سعر الشراء، رؤية سعر الجملة، تعديل الكمية، رؤية إجمالي المستحق، بطاقات صناديق لوحة التحكم، خصم السطر، خصم الفاتورة.
- إخفاء صلاحية سعر الشراء يخفيه من صفحة المنتجات ومن البحث في فاتورة البيع. **لكن إذا كان العمل بدون اتصال مفعّلًا، فالنسخة المحلية من المنتجات على الجهاز ما زالت تحتوي على سعر الشراء.**
- قد يحتاج المستخدم إلى تسجيل الخروج والدخول مجددًا لتظهر الصلاحيات الجديدة.

> نصيحة: لأمين الصندوق امنح عادةً فواتير البيع والسندات، وأخفِ سعر الشراء والأرباح ولوحة التحكم.
